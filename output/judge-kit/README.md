# Fursah judge kit

Use these materials in this order:

1. Open `https://fursah.org/judge-demo` and keep it ready in a browser.
2. Present `../presentation/fursah-judge-pitch.pptx` using its speaker notes.
3. Follow `fursah-live-demo-script.md` for the product demonstration.
4. Give judges `../pdf/fursah-judge-handout.pdf` or the full submission report.
5. Use `fursah-judge-qa.md` for questions and `fursah-validation-protocol.md` when discussing next steps.

The work-in-progress business-analysis PDF is intentionally excluded.
