# Fursah live demo script

Target duration: 3 minutes. Keep `/judge-demo`, `/standards`, and `/login/demo` open before presenting.

## 1. Judge route — 20 seconds

- Open `/judge-demo`.
- Point to the four published criteria and the three evidence counts.
- Say: “This route is an evidence index, not a marketing page.”

## 2. Student evidence — 50 seconds

- Select Abdullah Al-Ghamdi from `/login/demo`.
- Open the readiness breakdown.
- Reconstruct the displayed total from the five published weighted components.
- Point to evidence status, confidence, and the recommended next action.

## 3. Grounded assistant — 35 seconds

- Ask the first suggested question about the readiness result.
- Point out that the answer explains stored platform facts.
- Show the disclosed model and grounding versions.
- Say: “The assistant explains the record; it is not the scoring authority.”

## 4. Governance — 45 seconds

- Switch to the administrator demo account.
- Show extraction proposals and human review attribution.
- Open Governance and show appeals, overrides, and the suppression floor.
- Open the Y.3172 trace from the same page.

## 5. Ecosystem loop — 20 seconds

- Briefly switch between employer and university demo roles.
- Show the same skill language moving from vacancy evidence to curriculum action.

## 6. Close — 10 seconds

- Return to `/judge-demo`.
- Say: “Every key claim is linked, exportable, and bounded by an explicit limitation.”

## Failure-safe route

If the assistant is unavailable, continue with the deterministic score, evidence registry, governance log, and standards mapping. Do not claim a live AI response that the judge did not observe.
